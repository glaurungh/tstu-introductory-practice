# АННОТИРОВАННЫЙ ОТЧЁТ

## по ознакомительной практике

**Студент:** Томилин Вячеслав

**Период прохождения практики:** с 29.06.2026 по 26.07.2026

---

Практика проходила в период с 29.06.2026 по 26.07.2026.

На начальном этапе практики был проведён анализ существующих подходов к созданию веб-страниц с использованием HTML и CSS. Были изучены основы семантической разметки HTML5, включая правильное использование тегов `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, а также принципы создания документа с указанием языка, кодировки и мета-тегов. Были освоены базовые свойства CSS: работа с текстом, шрифтами, цветом, единицами измерения (`px`, `em`, `rem`, `vw`, `vh`), а также каскадность стилей и специфичность селекторов.

В результате были выполнены задания по оформлению контента веб-страниц: стилизация текстовых элементов с иерархическими заголовками, подключение нестандартных шрифтов посредством `@font-face`, создание вложенных списков, много-colончатая вёрстка с помощью CSS Multi-column Layout Module, работа с медиа-элементами (`<video>`), построение таблиц с объединением ячеек (`colspan`, `rowspan`), создание форм с элементами ввода и применение псевдоклассов `:nth-child()` для программной стилизации элементов. Также была реализована работа со свойством `overflow` для создания компонента уведомлений с прокруткой и усечением текста.

В рамках изучения позиционирования элементов были освоены все типы CSS-позиционирования: относительное (`relative`), абсолютное (`absolute`), фиксированное (`fixed`), а также работа со свойством `float` для создания многоколоночных макетов и `z-index` для управления порядком наложения элементов. Были выполнены практические задания по созданию интерактивных карточек с эффектами наведения, позиционированию геометрических фигур с использованием CSS-переменных и функции `calc()`, реализации фиксированного заголовка и наложению полупрозрачных элементов.

Для создания современных адаптивных макетов была изучена технология CSS Flexbox. Были освоены свойства `display: flex`, `flex-direction`, `flex-wrap`, `justify-content`, `align-items`, `flex-grow`, `flex-shrink`, `flex-basis`, а также свойство `order` для изменения визуального порядка элементов. В результате были реализованы: двухколоночный макет с обращённым порядком элементов в шапке, каталог товаров с переносом элементов, «липкий» подвал с помощью `justify-content: space-between`, центрирование содержимого кнопки, гибкая трёхколоночная раскладка и сортировка элементов по значению прогресса.

Для создания сложных сеточных макетов была изучена технология CSS Grid. Были освоены свойства `display: grid`, `grid-template-columns`, `grid-template-rows`, `grid-template-areas`, `grid-column`, `grid-row`, а также функции `repeat()` и `auto-fill` для создания адаптивных сеток. В результате были реализованы: многоколоночная сетка с разной шириной колонок, макет редактора кода с размещением панели файлов, основного окна и подвалов, а также шаблон сайта с именованными областями и каталог товаров на основе 12-колоночной сетки с использованием классов-утилит.

В ходе практики были изучены принципы адаптивной вёрстки. Были освоены подходы к созданию резиновых макетов с использованием процентных значений ширины, минимальных и максимальных ограничений, а также flex-модели с параметрами `flex: 1 1 200px`. Были созданы медиа-запросы с тремя контрольными точками (1200 px, 600 px и менее 600 px), обеспечивающими адаптивное отображение карточек товаров. Также была разработана таблица стилей для печати (`@media print`), переопределяющая цвета и фон для корректного вывода на бумагу.

Для повышения эффективности разработки была изучена препроцессорная система SASS/SCSS. Были освоены возможности вложенности селекторов, использование символа `&` для создания модификаторов и псевдоклассов, а также создание миксинов (`@mixin`) с параметрами и их вызов с помощью директивы `@include`. На продвинутом уровне были изучены: миксины как функции с передачей параметров, пользовательские функции (`@function`), условные конструкции (`@if`) для обработки граничных значений и циклы (`@each`) для генерации CSS-классов на основе ассоциативных массивов. В результате были созданы переиспользуемые компоненты: миксин для градиентного фона, функция расчёта ширины контейнера по количеству колонок и генератор утилитарных классов для цветовых тем.

В рамках изучения CSS-трансформаций были освоены двумерные преобразования элементов: сдвиг (`translate`), поворот (`rotate`), масштабирование (`scale`) и наклон (`skew`). Были реализованы: центрирование модального окна с помощью `translate(-50%, -50%)`, эффект переворота карточки по оси Y с использованием `backface-visibility: hidden`, масштабирование карточек при наведении и создание декоративного логотипа с тенью посредством комбинации `skewY()` и псевдоэлемента `::before` с `skewX()`.

Для быстрого создания адаптивных веб-страниц была изучена CSS-фреймворк Bootstrap 5. Были освоены компоненты сеточной системы (классы `col-*`, адаптивные колонки), типографические утилиты, компоненты таблиц с тёмной темой и полосатой раскраской, а также компоненты форм с адаптивным расположением полей ввода. В результате была создана страница фотомагазина с адаптивной сеткой, таблица сравнения профессий и форма ввода данных банковской карты.

В рамках индивидуального задания была разработана многостраничная образовательная веб-страница «Научиться учиться» на тему эффективных подходов к обучению. Сайт содержит две версии: краткую (6 секций) и полную (11 секций), включая разделы с техниками Барбары Оакли, методом Фейнмана, принципами Джоша Кауфмана, видеоматериалами TED и полезными ресурсами. Вёрстка выполнена по методологии БEM (Block Element Modifier) с организацией файлов по вложенной структуре: каждый блок, элемент и модификатор расположен в отдельном CSS-файле. Были реализованы декоративные анимации вращения с помощью `@keyframes`, тёмная тема для секции Кауфмана, интеграция внешних видео через `<iframe>` и адаптивные компоненты на основе Flexbox.

Для проверки корректности решений использовался инструмент визуального регрессионного тестирования Playwright, сравнивающий скриншоты отрендеренных страниц с эталонными шаблонами. Для модулей SASS применялся тестовый фреймворк Jest с модулем `sass-true` для проверки корректности компиляции SCSS-кода. Все решения были размещены в репозитории Git с раздельной организацией по модулям.

Практика позволила получить практические навыки работы с HTML5 и CSS3, изучить методы адаптивной и семантической вёрстки, освоить технологии Flexbox и Grid, а также научиться работать с препроцессором SASS и фреймворком Bootstrap 5. Полученные знания и опыт будут полезны в дальнейшем для эффективного создания современных веб-приложений.

По завершении практики был оформлен отчёт.
